# 我的个人主页 · My Homepage

黄文轩的个人主页：静态站点（HTML + CSS + JS + globe.gl 3D 地球 + Supabase 留言反馈）。

## 本地运行

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765
```

## 部署（三选一，均免费）

| 平台 | 方式 | 免费 URL |
|---|---|---|
| GitHub Pages | git push 仓库后开启 Pages | `https://<用户名>.github.io` |
| Vercel | 导入 GitHub 仓库或 CLI 部署 | `https://<项目名>.vercel.app` |
| Netlify Drop | 拖拽本文件夹到 app.netlify.com/drop | `https://<随机名>.netlify.app` |

> 纯静态项目，无需构建命令；所有资源为相对路径，部署到任意子路径均可正常工作。
